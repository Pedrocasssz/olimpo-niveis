# olimpo-niveis

Níveis de value area (VAH, VAL, POC) de BTC, ETH e SOL usados nos posts do Olimpo no X, atualizados de hora em hora.

- `out/resumo.md`: leitura rápida por ativo.
- `out/<ATIVO>.json`: níveis, contexto de mercado e velas diárias e semanais.
- `out/status.json`: fontes de dados da última atualização.

Gerado automaticamente. Não é recomendação de investimento.
